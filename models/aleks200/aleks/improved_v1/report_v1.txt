REFACTORING REPORT: IMPROVED RESNET18 ANALYSIS
Date: January 31, 2026
Subject: Optimization and Refactoring of ResNet18SE Training Script

1. EXECUTIVE SUMMARY
This report details the modifications made to the 'aleks_train_resnet18_se_SGD_cbfl.py' script. The goal was to enhance the model's generalization capabilities on facial expression datasets by correcting sampling strategies, refining data usage, and stabilizing the training process.

2. KEY MODIFICATIONS

A. DATA PIPELINE OPTIMIZATION
- Merged Training Data: To maximize the learning signal, the previously separate 'eval' dataset has been merged into the 'train' dataset.
- True Validation: The 'test' folder is now strictly used for validation (reported as "Val Acc" during training) to provide a realistic measure of generalization.
- Final Evaluation: A new automatic step was added to evaluate the best model on the separate 'test_datasets' directory immediately after training concludes.

B. ALGORITHMIC IMPROVEMENTS
- Addressing Class Imbalance:
  > Previous Approach: Class Balanced Focal Loss.
  > New Approach: WeightedRandomSampler combined with CrossEntropyLoss.
  > Why: Focal Loss can force the model to overfit to noisy or mislabeled examples (common in emotion datasets). The Weighted Sampler ensures the model sees all emotions equally without penalizing it for data incorrectly, leading to robust feature learning.

- Scheduler Stabilization:
  > Added a Linear Warmup (5 Epochs) to the Cosine Annealing Scheduler. This prevents the gradients from diverging early in training when the learning rate is high.

C. REGULARIZATION ADJUSTMENTS
- Removed Random Erasing: Occlusion techniques like Random Erasing often hide critical facial features (eyes, mouth) necessary for emotion recognition. This was removed to improve performance.
- Retained Random Affine: Geometric transformations (rotation, shear) were kept as they simulate realistic head pose variations.

D. LOGGING AND OUTPUT
- CSV Reporting: Results are now logged to a structured CSV file ('../results/aleks_train_resnet18_se_SGD_cbfl_results.csv') for easy import into Excel or Sheets.
- Metrics Tracked: Epoch, Learning Rate, Training Loss/Accuracy, and Validation Loss/Accuracy.

3. HOW TO EXECUTE

- Standard Training:
  python3 aleks_train_resnet18_se_SGD_cbfl.py

- Resume Training:
  python3 aleks_train_resnet18_se_SGD_cbfl.py --resume

- Verify Configuration (Dry Run):
  python3 aleks_train_resnet18_se_SGD_cbfl.py --dry-run
